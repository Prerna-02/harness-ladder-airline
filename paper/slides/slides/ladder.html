The harness ladder

Four levels, each adds one layer

H0

Rulebook

The standard agent, given the airline policy as written.

H1 = H0 +

Clear rules

Policy rewritten as short numbered rules, plus a checklist read back before any change.

H2 = H1 +

Code checks

10 rules checked in code. A change that breaks one is blocked, with the reason.

H3 = H2 +

Confirm + verify

No change without a clear “yes”. A second model call checks each change after it runs.

Harness ladder · τ²-bench airline

The levels are cumulative. H2’s code checks cover things like basic economy flights that can’t be changed, bag prices and payment limits. They only read the database; they never change it.
