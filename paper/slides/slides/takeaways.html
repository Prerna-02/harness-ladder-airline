What a team should do

Measure first, then add only the layer that fixes something

1

Test your model bare

Run it on your own tasks with no harness. Count rule-breaking and missed steps separately.

2

Write rules clearly first

Clear numbered rules alone took DeepSeek from 6 rule breaks to 0, for almost no cost.

3

Code checks as insurance

They rarely fired and almost never blocked a correct change. Cheap to keep on.

4

Don’t assume pricier is better

Here a cheap model with a harness matched or beat a 20–65× pricier one.

Harness ladder · τ²-bench airline

The one-line answer to the title: a cheap agent needs as much harness as it has rule problems. For DeepSeek that was clear rules plus code checks; for Haiku and Qwen, almost none.
