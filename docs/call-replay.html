    Where the harness layers will sit

    This replay is H0. In the study, the same call runs again with more rails added between the agent and the airline system, one layer at a time.

    H0

    Rulebook pasted into the prompt. Nothing else.

    “Here’s the manual, good luck.”
    H1

    Rules rewritten as short numbered steps, plus a checklist the agent restates.

    A clear job aid.
    H2

    Code checks every database-changing call and blocks rule breaks with a reason.

    A supervisor who says “no, because…”.
    H3

    Customer must say “yes” before a change; a second agent verifies the database after.

    Measure twice, cut once.
